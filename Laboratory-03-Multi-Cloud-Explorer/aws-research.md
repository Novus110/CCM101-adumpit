# Amazon Web Services (AWS)

## Brief Overview

Amazon Web Services (AWS) is a pioneer and market-leading cloud service platform launched by Amazon.com in 2006. AWS offers over 200 fully featured services from data centers globally, spanning basic compute and storage to advanced machine learning, Internet of Things (IoT), and serverless architectures.

## Global Infrastructure

- **Regions:** AWS operates in over 33 geographic regions worldwide (such as US East, Europe, and Asia Pacific). Each region is an isolated geographical area.
- **Availability Zones (AZs):** Each AWS Region consists of multiple (typically 3 or more) discrete, physically separated Availability Zones. Each AZ possesses independent power, cooling, and networking.
- **Edge Locations & Points of Presence (PoP):** AWS maintains hundreds of edge locations globally to power its Content Delivery Network (Amazon CloudFront), reducing latency for end users.

## Cloud Management Console

The AWS Management Console is a web-based portal used to manage AWS resources. It provides a search bar for quick resource navigation, customizable dashboards, integrated access to the AWS CloudShell (in-browser terminal), and unified monitoring via AWS CloudWatch.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud):** Resizable, virtual compute instances (VMs) providing full control over instance types, operating systems, and networking.
2. **Amazon S3 (Simple Storage Service):** Highly durable, scalable object storage designed to store and retrieve any amount of data from anywhere.
3. **Amazon RDS (Relational Database Service):** Managed relational database service supporting multiple database engines, including MySQL, PostgreSQL, Oracle, and SQL Server.
4. **AWS Lambda:** Serverless event-driven compute service that executes code in response to events without requiring server provisioning or administration.

## Three (3) Advantages

- **Market Dominance & Maturity:** Vast service offerings, extensive documentation, and a mature partner ecosystem.
- **Granular Security & Compliance:** Comprehensive security controls via AWS Identity and Access Management (IAM) alongside compliance certifications across industries globally.
- **Scalability & Breadth:** Unmatched depth of features supporting high-capacity web applications, big data workloads, and enterprise migrations.

## Typical Enterprise Use Cases

- **Data Warehousing & Big Data Processing:** Enterprise analytics pipelines using Amazon Redshift and EMR.
- **Enterprise App Migration:** Migrating legacy on-premises applications to high-availability multi-AZ environments.
- **Backup & Disaster Recovery:** Utilizing S3 and Glacier for compliant, long-term archive and offsite disaster recovery setups.
