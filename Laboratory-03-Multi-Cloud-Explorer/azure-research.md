# Microsoft Azure

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform, launched in 2010. It is designed to help organizations build, run, and manage applications across multiple clouds, on-premises environments, and at the edge using open-source tools and frameworks. Azure is particularly dominant among enterprises already invested in Microsoft technologies (such as Active Directory, SQL Server, and Windows Server).

## Global Infrastructure

- **Regions:** Azure spans over 60–70 global regions—one of the largest global footprints among cloud providers.
- **Availability Zones:** Regions feature Availability Zones (groups of physically separate data centers with independent power and cooling) to ensure high-availability application design.
- **Regional Pairs:** Many Azure regions are paired with another region within the same geography (e.g., East US paired with West US) to assist with business continuity and disaster recovery isolation.

## Cloud Management Console

The Azure Portal is a unified, web-based console built around a customizable "blade-based" graphical user interface. It provides tile-based dashboards, integrated access to Azure Cloud Shell (supporting PowerShell and Bash), resource search, and billing monitoring via Azure Cost Management.

## Four (4) Core Services

1. **Azure Virtual Machines (VMs):** On-demand, scalable computing resources for running Linux or Windows virtual machines.
2. **Azure Blob Storage:** Object storage solution optimized for storing massive amounts of unstructured data such as text or binary data.
3. **Azure SQL Database:** Fully managed, scalable relational database engine built on Microsoft SQL Server with automated patching and backups.
4. **Azure App Service:** Fully managed Platform as a Service (PaaS) for building, deploying, and scaling web apps and APIs rapidly.

## Three (3) Advantages

- **Seamless Microsoft Integration:** Native alignment with Active Directory (Microsoft Entra ID), Office 365, Windows Server, and SQL Server.
- **Hybrid Cloud Leadership:** Advanced hybrid cloud solutions through Azure Arc and Azure Stack, allowing seamless management between on-premises and cloud resources.
- **Enterprise Licensing & Discounts:** Hybrid benefit programs that allow existing Windows and SQL Server licenses to be applied directly in Azure.

## Typical Enterprise Use Cases

- **Hybrid IT Deployments:** Synchronizing on-premises Active Directory environments with the cloud while maintaining hybrid workloads.
- **Enterprise ERP & Database Hosting:** Hosting mission-critical enterprise platforms like SAP HANA or large-scale Microsoft SQL databases.
- **Identity & Access Management:** Centralizing global user authentication using Microsoft Entra ID (formerly Azure AD).
