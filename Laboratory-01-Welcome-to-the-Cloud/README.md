# Laboratory 1: Welcome to the Cloud

## Mission Overview
This laboratory activity served as an onboarding mission for a Junior Cloud Infrastructure Engineer Trainee role. It focused on getting familiar with a Linux environment, gathering system information, organizing files, and building a professional GitHub portfolio.

## Objectives
- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.

## Activities Performed
- Created a new user account with sudo privileges and logged in.
- Investigated the Linux distribution, kernel version, CPU, memory, and disk space.
- Built a folder structure (Notes, Reports, Screenshots) inside the home directory.
- Created a personal about-me.md file.
- Set up a public GitHub repository and organized it into the required folder structure.
- Committed and pushed all work to GitHub.

## Linux Commands Used
- `whoami` – displays the current logged-in user
- `pwd` – shows the current working directory
- `hostname` – displays the system's hostname
- `lsb_release -a` – shows Linux distribution details
- `uname -r` – shows the kernel version
- `lscpu` – displays CPU information
- `free -h` – shows memory usage in human-readable format
- `df -h` – shows disk space usage
- `mkdir` – creates directories
- `nano` – opens a terminal text editor
- `git clone/add/commit/push` – manages and syncs a Git repository

## Skills Learned
- Navigating and gathering information in a Linux environment
- Creating and organizing files/directories via the command line
- Writing documentation using Markdown
- Using Git and GitHub for version control and portfolio building
