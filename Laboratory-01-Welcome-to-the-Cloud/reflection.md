# Reflection

Completing this laboratory activity gave me hands-on experience working inside a Linux environment for the first time in a professional context. I learned how to create and manage user accounts, gather system information, and organize files using the command line. I also practiced using Git and GitHub to build and maintain a version-controlled portfolio, which helped me understand how real cloud engineers document and share their work. One challenge I faced was losing progress when my KillerCoda session expired before I could push my changes, which taught me the importance of committing and pushing frequently instead of waiting until the end. Overall, this activity strengthened my confidence in navigating Linux systems and following professional documentation practices.
